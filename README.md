# Housing market demo

Demo project for the talk "GitHub Copilot app: AI Agents for Developers, Knowledge Workers, and Everyone in Between."

Agents build a website, an Excel workbook, and a PowerPoint briefing from public U.S. housing data (FHFA House Price Index and CFPB HMDA). A fourth agent uses WorkIQ to build a session brief.

- Data: [data/README.md](data/README.md)
- Talk outline and prompts: [talk/outline.md](talk/outline.md)
- Agent instructions: [AGENTS.md](AGENTS.md)

Built from public FHFA and CFPB data. Not an official Fannie Mae, FHFA, or CFPB product.
