# Housing market demo: starting point

This branch is the starting point for a live run of the demo. It has the agent instructions ([`AGENTS.md`](AGENTS.md)), the slide template, and the talk files. It has no data and no results, so the agents do all of the work on stage.

For instructions, prompts, and finished results, see the [`main` branch](https://github.com/DanWahlin/housing-market-demo).
